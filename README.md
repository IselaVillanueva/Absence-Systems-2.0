# Employee Absence API Basic: read, understand, adapt

This small starter implements **Employee** and **Absence Request** records. Alice (1), Bob (2), and Charlie (3) are fictional. All the API code to study is in **[main.py](main.py)**.

This is an independent student starter. The lecturer's larger reference also demonstrates related models and Python objects; it is not needed for this first activity.

## 1. Run your own copy

Repository: [Employee-Absence-API-Basic](https://github.com/DevidMontecchiari/Employee-Absence-API-Basic).

**In the browser:** on GitHub select **Code > Codespaces > Create codespace**. This creates your own environment, not access to the lecturer's running application. To keep and push changes to your own repository, fork the starter first and open your Codespace on that fork.

Wait for setup to finish. In a terminal at the repository root, enter only:

```sh
python run.py
